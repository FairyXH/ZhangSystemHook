# 1.2.1：修复系统框架作用域

- 修复 API 102 推荐作用域：使用 `system` 表示系统框架（system_server），替换沿用旧 API 的 `android`。
- 设置页“申请核心与目标应用作用域”同时申请系统框架、设置存储、ColorOS 桌面和名单应用，自动去重。
- 更新作用域说明；所有原有功能保持保留。

## 安装

- 下载 `ZhangSystemHook-1.2.1.apk`，使用与 1.1.7、1.2.0 相同的正式签名，versionCode 为 21，可覆盖升级。
- 更新后在框架的模块作用域页确认勾选“系统框架”（`system`），再重启设备。已有作用域不会因更新 APK 自动补选。
- 若看不到系统框架，请在框架作用域页的筛选菜单中显示系统应用；也可在模块设置页申请核心作用域并批准框架提示。
- 需要支持 libxposed API 102 的框架。

## 验证

- Release/R8 构建、完整 Debug Lint 和 22 项单元测试通过。
- 检查最终签名 APK 中的 `META-INF/xposed/scope.list`，包含 `system`；校验正式签名及版本信息。
- 尚未在真实 API 102 框架设备验证系统服务注入。
