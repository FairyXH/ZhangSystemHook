# 1.2.0：API 102 重构与 iOS 风格界面

## 核心升级

- 迁移至原生 libxposed API 102，移除 YukiHookAPI、旧 XposedBridge 入口及相关生成依赖。
- 保留无障碍防检测、音频模式与路由、官方/增强截图、DPM、ColorOS 最近任务锁及原配置和测试能力。
- 修复增强截图加载分支、Cursor 逻辑行映射、同一方法多功能 Hook 注册和扩展无障碍查询。
- 配置使用远程偏好变更通知与内存快照，支持旧配置迁移、离线编辑和 XML 导入导出。

## 性能与界面

- 音频诊断日志改为惰性表达式并限流；缓存反射方法、字段和调用者分类。
- 配置后台串行写入；应用列表后台加载、搜索防抖和图标缓存。
- iOS 风格大标题、分组圆角列表、绿色胶囊开关，支持深色模式。

## 安装要求

- 正常安装或覆盖升级请下载 **ZhangSystemHook-1.2.0.apk**，使用与 `1.1.7` 相同的正式签名，versionCode 为 20。
- Debug 包仅供测试，未签名包仅供自行签名使用；附件 `SHA256SUMS.txt` 提供文件校验值。
- 必须使用支持 **libxposed API 102** 的框架；仅支持传统 API 的旧版 LSPosed 无法加载。
- 更新模块后重启系统。推荐作用域为 `android`、`com.android.providers.settings`，ColorOS 桌面功能另需 `com.android.launcher`。
- 应用内扩展及增强截图需目标应用作用域；设置页可申请动态作用域。
- 官方截图回调要求 Android 14+；其他内部 Hook 以目标 ROM 的方法签名为准。

## 验证

- Debug、Release/R8、完整 Lint 和 22 项单元测试通过。
- Android 16 模拟器已验证设置页深浅色、开关触控、应用列表、搜索和本地配置持久化。
- 尚未在真实 API 102 框架设备验证系统服务命中、ColorOS 签名、真实电话/蓝牙/听筒路由和截图分发覆盖。
